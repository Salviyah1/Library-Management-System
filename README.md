# Library Management System

A console-based Library Management System developed using Core Java and Object-Oriented Programming concepts.

## Features

- Add new books
- View all available books
- Search books by ID
- Update book details
- Delete books
- Issue books to students
- Return issued books
- Calculate fines for late returns
- View currently issued books
- Validate user input

## Technologies Used

- Java
- OOP
- ArrayList and Collections
- Java Date and Time API
- Exception Handling

## Project Structure

- `Book.java` – Stores book information.
- `IssueRecord.java` – Stores book borrowing and return details.
- `LibraryService.java` – Handles library operations and business logic.
- `Main.java` – Provides the menu-driven user interface.

## How to Run

1. Clone this repository.
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Compile the Java files.
4. Run `Main.java`.

## Current Limitations

This version stores information in memory using ArrayList. Data added during execution is not retained after the application closes.

## Future Improvements

- Add MySQL database integration.
- Implement file-based data persistence.
- Develop REST APIs using Spring Boot.
- Add automated unit tests.
- Implement user authentication and authorization.
